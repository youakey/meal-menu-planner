# Проект CookPlanner: Инструкции для Claude

## Технологический стек
- **Frontend:** React (Vite) + TypeScript
- **Стили:** Tailwind CSS
- **Backend/Auth:** Supabase
- **Deployment:** GitHub Pages

## Архитектура данных
- Ингредиенты -> Блюда (состоят из ингредиентов) -> Меню (состоит из блюд и ингредиентов).
- **Важно:** Все расчеты стоимости должны быть синхронизированы.

## Правила кодирования
- Используй функциональные компоненты и TypeScript.
- Для стилей используй ТОЛЬКО Tailwind CSS классы.
- Всегда проверяй наличие `user_id` при запросах к Supabase (RLS).
- **Безопасность:** Запрещено изменять структуру существующих таблиц Supabase без явного подтверждения, чтобы не удалить данные пользователей.

## Специфические задачи (Current Focus)
1. **Смена пароля:** Использовать `supabase.auth.updateUser`.
2. **UI Шторка:** В `DishEdit.tsx` реализовать скрытие верхней панели при скролле вниз и появление при скролле вверх.
3. **Оптимизация:** Минимизировать лишние рендеры в списках.
4. **Универсальное Меню:** Добавить выбор "Блюдо/Ингредиент" в планировщик.

## Команды проекта
- `npm run dev` — запуск локально
- `npm run build` — сборка проекта
- `npm run lint` — проверка линтером
